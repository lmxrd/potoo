# potoo frontend

The dashboard: a client-rendered React SPA built with Vite, Tailwind CSS 4,
shadcn/ui (on Base UI), TanStack Router (file-based) and TanStack Query,
managed with pnpm. The backend embeds its build (`dist/`) in the binary.

## Commands

From the repository root, `mise run dev:frontend`, `check:frontend` and
`test:frontend` (they generate the SDK first). Here:

| Command      | What it does                              |
| ------------ | ----------------------------------------- |
| `pnpm dev`   | Dev server at http://localhost:5173       |
| `pnpm build` | Production build into `dist/`             |
| `pnpm test`  | The Vitest unit tests                     |
| `pnpm check` | tsc, oxlint and oxfmt --check (read-only) |
| `pnpm fix`   | oxlint --fix and oxfmt                    |

## Layout

- `src/routes/` — file-based routes (one file per route, `__root.tsx` for the shell)
- `src/components/` — the app's components by feature (`auth/`, `stats/`, `settings/`, `admin/`, `common/`); `ui/` holds the shadcn/ui primitives
- `src/lib/` — logic and helpers (dates, filters, ranges, theme, labels), with their tests
- `src/routeTree.gen.ts` — generated by the Vite plugin; committed, do not edit
