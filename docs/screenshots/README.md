# Screenshots

The README references these files. Take them on a running instance
(`mise run dev`, then browse the Vite URL), with the seeded data
(`mise run seed`):

1. `dashboard.png` — the overview at `/`: all sites selected.
2. `site.png` — a site's page: the tracking snippet generator with a
   checkbox or two checked, and the site settings.
3. `dashboard-stats.png` — the dashboard's stats: the breakdowns.
4. `dashboard-stats-2.png` — the rest of the breakdowns.
